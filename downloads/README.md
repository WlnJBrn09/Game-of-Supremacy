# Installable test build

`GameofSupremacy_v0.3.0.apk` is the installable Android debug build (version 0.3.0, versionCode 4) produced from the source in this branch: the responsive phone and tablet interface, owner-coloured map, computer turns played on the map, undo, AUTO placement and match options. It supports Android 8.0+ on ARMv7, ARM64 and x86-64, requests only the vibration permission (for haptic feedback) and no Internet access. Download the file and open it on Android to install.

The debug APK is included here so the game can be tried directly without setting up Android Studio. It is not a Play Store release. CI also builds an APK on every push (the `apk` artifact of the "Build and test" workflow) and attaches it to releases for tags named `v*`; a signed release APK is added there once signing secrets are configured. To build it yourself run `./gradlew :core:test :android:assembleDebug`; output is `android/build/outputs/apk/debug/android-debug.apk`. `SHA256SUMS` records the included build's digest; verify it with `sha256sum -c downloads/SHA256SUMS` from the repository root. To publish a new build here, bump `versionCode`/`versionName` in `android/build.gradle`, rebuild, copy the output here under the new name and refresh the digest. No private signing key is checked in.

**If you installed an earlier build:** this APK is signed with a different debug key, so Android will refuse to install it over the old one. Uninstall the old app first; its saved game is deleted with it. (Saves themselves are compatible: a 0.2.1 save would load in 0.3.0.) A debug key is generated per build machine, so any APK you build yourself will likewise need the previous one uninstalled.

This build has been built and inspected, and its interface exercised on desktop at phone sizes; CI runs it on an Android emulator. See `docs/VERIFICATION.md` for exactly what has and has not been checked.
